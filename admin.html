Connexion

Cet espace modifie ton site directement. Pour t'y connecter, il faut une « clé » GitHub (à créer une seule fois, 2 minutes) :

  1. Ouvre GitHub → Nouvelle clé d'accès.
  2. Nom : espace-contenu. Expiration : 1 an.
  3. « Repository access » : Only select repositories → sarahleduc-site.
  4. « Permissions » → Contents : Read and write.
  5. Clique « Generate token », copie la clé, colle-la ci-dessous.

La clé reste seulement dans ce navigateur. Ne la partage avec personne.
